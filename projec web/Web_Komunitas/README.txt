KOMUNITAS NUSANTARA — VERSI RAPI PEMULA

Cara menjalankan:
1. Buka folder KN_RAPI di VS Code.
2. Klik index.html.
3. Tekan Alt+B jika memakai ekstensi Live Server/Browser.
4. Internet diperlukan karena Bootstrap, Font Awesome, AOS, Swiper, Leaflet, Chart.js, dan SweetAlert2 dipanggil dari CDN.

PETA FILE:
- index.html = struktur/tampilan website.
- css/style.css = semua gaya visual.
- js/data.js = data contoh anggota, provinsi, event, berita, dll.
- js/app.js = pengatur utama. Sengaja dibuat pendek.
- js/core/ = navigasi, tema, utilitas.
- js/auth/ = login, daftar, profil.
- js/pages/ = fitur tiap halaman.
- js/dashboard/ = dashboard anggota dan admin.
- js/effects/ = animasi scroll.

Catatan:
Website ini masih DEMO/front-end. Login, pendaftaran, komentar, like, event, dan admin belum terhubung database PHP/MySQL.
