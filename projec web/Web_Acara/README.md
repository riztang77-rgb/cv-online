# NEXORA Future Event — Pure HTML/CSS/JS

Website acara modern tanpa PHP, MySQL, XAMPP, Composer, atau backend.

## Jalankan
1. Extract ZIP.
2. Buka folder.
3. Klik `index.html`.
4. Di VS Code bisa langsung `Alt + B`.
5. Semua data demo disimpan di `localStorage` browser.

## Fitur
Landing + countdown, tentang acara, speaker, rundown + search/filter, pendaftaran, tiket digital, payment proof simulation, QR-style ticket, check-in, feedback/rating, galeri, sertifikat printable, dark/light mode, responsive, animasi scroll, login-ready local architecture, dashboard statistik, CRUD peserta, pagination, search, sorting-ready, notifikasi, upload file, WhatsApp/Maps-ready data, export CSV, dan penyimpanan browser.

## Catatan
Karena ini murni frontend, login, pembayaran, QR verification, realtime server, dan data admin bersifat simulasi/localStorage. Untuk sistem produksi yang benar-benar aman diperlukan backend/API.
