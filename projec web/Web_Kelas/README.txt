KODENUSA — VERSI SIMPLE

Struktur:
- index.html       = halaman utama
- css/style.css    = seluruh CSS (dipisah, tidak dicampur ke HTML)
- js/app.js        = seluruh JavaScript digabung menjadi satu file
- assets/          = folder aset gambar/dokumen

Cara buka:
1. Buka folder ini di VS Code.
2. Buka index.html.
3. Jalankan dengan Live Server atau buka langsung di Chrome.

Catatan:
- Library seperti Bootstrap, AOS, Swiper, Leaflet, Chart.js, dan SweetAlert2 masih memakai CDN.
- Data website masih berupa simulasi frontend.
